# Регламент полевой инвентаризации (Getac V110)

Краткий порядок работы на объекте. Особенность задачи: много камер, коммутаторов,
регистраторов и другого оборудования на нескольких этажах и в шкафах.

---

## 1. Перед выездом

- [ ] Ноутбук заряжен (¾ и больше), зарядное — в сумке.
- [ ] Сканер штрихкодов и COM-кабель (при проводном сканере) — взяты.
- [ ] На ноутбуке запускается приложение (`InventorySurvey.exe` или `run_inventory.bat`).
- [ ] Предстартовая проверка без красных ошибок (батарея, диск, база, экспорт).
- [ ] Свободное место на диске ³ 5 ГБ.

Папки данных (рядом с программой):
`data\inventory.db` — база, `data\photos\` — фото, `data\exports\` — Excel-отчёты,
`data\backups\` — резервные копии базы (держится 30 штук),
`data\logs\` — журнал работы (`app.log`) и разбор падений (`crash-*.txt`).

---

## 2. Старт сессии

1. Включить ноутбук, запустить приложение.
2. На стартовом экране: если есть активная сессия — «Продолжить обход».
   Иначе — заполнить «Объект» и «Инспектор», «Создать сессию».
3. Пройти «Проверку готовности»: всё зелёное или жёлтое — «Начать обход».
4. Выбрать локацию: этаж → помещение → (шкаф, юнит, ориентир). Кнопка сверху фиолетовая.

---

## 3. Обход: цикл на каждое устройство

1. Слева выбрать тип (камера / коммутатор / регистратор / …).
2. Отсканировать код: кнопка «ЗАЖЕЧЬ ЛАЗЕР» + считывание, либо аппаратная кнопка
   сканера, либо ручной ввод кода с этикетки.
3. Проверить в блоке «Активное устройство»: производитель, модель, S/N, MAC.
   Не хватает данных — кнопка «Подробно», вписать вручную.
4. Указать питание (PoE / 220 В) — проставляется по типу автоматически, проверить.
5. Указать связь («Связь» → вкладка «Связь»): для камеры/AP — коммутатор и порт,
   для коммутатора — вышестоящий коммутатор/port-uplink. Для камеры на регистраторе —
   канал NVR (D1…D16 или 1…32): в отчёте появится карта каналов «Регистраторы».
6. При проблеме — голосовая заметка («Заметка», говорить коротко и чётко в тихом месте)
   или напечатать вручную; фото при сомнении («Фото» камерой ноутбука, «📱 Телефон» —
   фотосъёмка телефоном: QR окно → камера телефона → снимок привяжется сюда же.
   Если камера труднодоступна (мачта, высотка) — снимите вдали, а отправьте из
   галереи, вернувшись в зону Wi-Fi).
7. Быстрый режим (внизу слева галочка «сохранять сразу») — устройство сохраняется сразу
   после скана, без карточки. Для «подозрительных» устройств снимите галочку
   и заполняйте карточку целиком.

### Статусы
- «Установлено» — работает, на месте.
- «Не работает» — индикации нет, не отвечает. Примечание обязательно.
- «Требует замены» — физические повреждения, следы вскрытия.
- «Резерв» — лежит на месте, но не подключено и не использует.
- «Не найдено» — по информации должна быть, обнаружить не удалось.
- «Демонтировано» — снято и лежит на полу/в коробке.

### Локация при смене шкафа
При переходе в другое помещение/шкаф — сменить локацию кнопкой сверху; все новые
устройства пойдут на неё же.

## 4. Дубликаты и неопределённые коды

- Окно «Возможный дубль»: та же камера — «Открыть существующее» (обновим данные),
  разные устройства — «Добавить как новое».
- Код из 12 hex-символов без разделителей может быть и MAC, и S/N — проверьте по этикетке.
- EAN-код — товарный код коробки. Он не пишется в S/N, копируется в примечание
  с пометкой «требует проверки».
- Нераспознанный код сохраняется в «Код сканирования» с типом «unknown» — попадает
  в лист «Проблемы» Excel-отчёта.

## 5. Завершение сессии

1. «Завершить обход» → сводка: всего устройств, дубли, без S/N и MAC, камеры без связи.
2. *Если есть прошлая инвентаризация объекта* — «🗂 Сверить с прошлой таблицей…»:
   выбрать старый Excel (например, таблицу прошлого выезда).
   Появится лист «Сверка»: совпало / изменилось (модель, IP, локация) / новое /
   пропало. Счётчики покажутся в сводке. Сверку можно пропустить и сделать позже.
3. «Экспорт Excel» → файл в `data\exports\`. Убедиться, что файл создан.
   Первый лист «Титул» — шапка отчёта для заказчика: объект, инспектор, даты,
   итоговые цифры и поля для подписей. Дальше «Устройства/Связи», затем «Сверка»
   (если сверяли), «Регистраторы» (если заполняли каналы камер), «Сводка/Проблемы».
4. «Завершить сессию». После завершения добавление в неё закрыто.
5. Не забыть скопировать `data\exports\*.xlsx` и `data\backups\` на флешку/в общую папку.

Если сессию завершили без экспорта — «История сессий» на стартовом экране:
выбрать сессию → «Экспорт Excel».

## 6. Если что-то пошло не так

| Проблема | Действие |
| --- | --- |
| Первый запуск exe идёт дольше обычного | Норма для onefile-сборки: файл распаковывается во временную папку. Если совсем медленно на полевом ноутбуке — запустите один раз заранее до выезда |
| Приложение закрылось/упало | Запустить снова, «Продолжить обход» — данные в SQLite + бэкапы. При следующем старте приложение само предложит открыть разбор: `data\logs\crash-<дата>.txt` (текст ошибки + трейсбек). Открыть и показать этот файл вместе с описанием «что делал в момент сбоя» |
| Сканер не читает | Настройки → режим «Только ручной ввод», вводить код с этикетки |
| Фото с телефона не проходит | Проверьте: телефон в той же Wi-Fi-сети; адрес открыт камерой с текущего QR (токен обновляется после перезапуска сессии); доступна кнопка «Старт приёма» в окне «📱 Телефон» |
| Телефон не видит ноутбук в сети | Включите «Сеть → Мобильный хот-спот» на ноутбуке; подключите телефон к этой сети; в окне «📱 Телефон» введите показанный адрес вручную, если QR не открывается |
| COM-порт занят/нет порта | Настройки → проверить порт и скорость; или временно ручной ввод |
| Голос не распознал | Напечатать заметку вручную; модель Vosk шумная — ближе к микрофону |
| Не открывается камера ноутбука | Фото необязательны — продолжить обход |
| Кончился заряд | Подключить питание; все данные сохранены, сессия остаётся активной |

## 7. Чек-лист железа перед пилотом (заполнить на ноутбуке)

- [ ] Сканер: подключение по COM3 @ 9600 подтверждено (предстартовая проверка зелёная).
- [ ] Сканер: читает MAC со штрихкода Hikvision/Dahua и S/N с боковой этикетки.
- [ ] Кнопки лазера Getac: F11/F12 реально зажигают луч («ЗАЖЕЧЬ ЛАЗЕР»).
- [ ] Режим HID (клавиатура): скан приходит в поле ручного ввода.
- [ ] Микрофон: короткая запись распознаётся (тихая комната).
- [ ] Камера: фото открывается и сохраняется в `data\photos\`.
- [ ] Фото с телефона: хот-спот поднят, QR открывается, тестовый снимок дошёл.
- [ ] Excel: экспорт создаётся и открывается без ошибок.
- [ ] Батарея: полный заряд держит ³ 4 часа активной работы с экраном.

## 8. Открытые решения (P1) — уточнить до/во время пилота

1. Режим и порт сканера: COM3/9600 — подтверждить на реальном сканере (или HID).
2. Формат выгрузки: достаточно нашего Excel или нужно титуловать под шаблон заказчика?
3. Глубина локации: нужен ли юнит (U-позиция) в шкафу или хватит этажа/помещения/шкафа?
4. Фото: обязательны для камер или по желанию?
5. Голос: нужны команды («добавить камеру», «не работает») или достаточно заметок?
6. Локальный ИИ (Ollama): убрано полностью — решение принято, код и настройки ИИ удалены.
7. Нумерация ID: CAM-001/SW-001… с нуля внутри каждой сессии — устраивает?
